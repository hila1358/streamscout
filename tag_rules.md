# Which Twitch tags to suggest

Suggest a tag only if it honestly describes this stream. The data shows what performed; these rules decide what fits.

**Always:** English

**Fits - pick the ones the numbers support:**
- How you play: blindplaythrough, firstplaythrough, nospoilers
- What you play: story, storygame, mystery, detective, puzzle, horror, psychologicalhorror, indie, visualnovel, narrative - only those that match the game
- The vibe: chill, cozy, positive, lurkerfriendly, chatty, vibes, communityfocused, scary (horror games only)

**Never suggest** (they describe a different streamer, not this stream):
- Places or nationalities (europe, japan, british, canadian, ...)
- Identity, gender, orientation or health (woman, girl, lgbtqia..., audhd, cptsd, ...) - unless listed under `personal_tags` in watchlist.json
- Music or performing (singer, goodmusic, rock, ...)
- Charity (togetherforgood) - unless it is a charity stream
- Adult or sexual tags (18over, feet, gooner, ...)
- Tags naming other games (bg3, poe2, ...), roleplay/dnd, vtuber/envtuber, varietystreamer

Twitch allows up to 10 tags. When the data is thin, say so instead of padding the list.
